ผมอยากให้คุณช่วย design teammate ทำงานร่วมกันแบบ workflow โดยมีแนวคิดที่ว่า Zero Trust Architecture รายละเอียดดึงนี้ 
1.รูปแบบ teammate โครงสร้างตามแบบ เอาตามfolder .agents แล้วฝั่ง .claude เป็นคน import ไปใช้ (สร้าง folder แยกออกมา)
2.งานที่ teammate ทำทุกงานต้องสามารถตรวจสอบได้ว่าทำถูกต้อง ถ้า teammate ทำไม่ถูกต้องต้องแก้จนกว่าจะถูกต้อง
3.ทุกๆครั้งที่ teammate ที่เป็น teamlead (current session) เมื่อทำงานต้องมีการเรียกใช้ grill-with-docs ก่อนเสมอ เพื่อเสนอหรือถามทิศทางการทำงานก่อนทุกครั้ง
4.เมื่อผ่าน grill-with-docs มาแล้ว จะมีการทำ spec และ task ที่เป็นส่วนกลางสำหรับให้ teammate หยิบไปทำ เมื่อ teammate ทำงานใน task เสร็จต้อง mark ว่า task นั้นเสร็จแล้ว
5.เมื่อ implement งานเสร็จ จะเป็นหน้าที่อีก teammate หนึ่งคอยตรวสอบ code ที่ implement ว่าตรงตาม spec ที่กำหนดหรือไม่ ถ้าไม่ตรงให้ทำ task อะไรสักที่เป็นเอกสารเพื่อส่งต่อให้ teammate อื่นไปแก้ไข
6.เมื่อโค้ดถูกต้องหมดแล้วต้องเป้นการทดสอบโค้ดที่ทำไป ถ้าเป็น api ควรสร้าง bruno ใช้สำหรับทดสอบ
ึ7.teammate ต้องทำการตรวจสอบการทำงานอย่างละเอียด ถ้าเป็น api ให้ run bruno เพื่อตรวจสอบ ถ้ามีการใช้ mcp ต่อ database ต้องเช็คข้อมูลระดับแต่ละ column ลงข้อมูลครบถ้วน ตาม spec หรือไม่ 
8.เมื่อทดสอบเสร็จเรียบร้อยแล้วจะต้องสรุปเป็นการทดสอบเป็นไฟล์ .md เพื่อให้ user ตรวจสอบ
9.teammate สามารถคุยกันเองได้ ถ้าเป็นเรื่องที่ต้องตัดสินใจให้แจ้ง teamlead แล้ว teamlead จะมาแจ้ง user อีกทีเพื่อให้ตัดสินใจ
10 เรื่องการตัดสินใจทาง teammate ต้องเสนอทางเลือกมาให้ด้วย ถ้า user ไม่พอใจให้เขาส่งทำตอบที่ต้องการมา
11 teammate ทำงาน coding และทดสอบ จนจบ flow ได้ และ user จะเป็นผู้มารีวิว และดูสรุปผลการทดสอบเท่านั้น
12 เมื่อทำเสร็จทั้งหมดแล้ว คุณสามารถ commit git ได้ แต่ห้าม  push code ไปยัง repo
13 skill แต่ละอย่างให้ teammate เลือกเองได้ตามความเหมาะสม
14 skill ไหนที่จำเป็นในการทำงานของผมที่อยู่ใน agent-team-roles ให้เอามาใช้ได้
